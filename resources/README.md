# Ressources

Ce répertoire contient les ressources diverses du projet.

## Contenu

- Images et graphiques
- Vidéos (liens ou petits fichiers)
- Fichiers audio
- Diagrammes
- Présentations

## Formats Recommandés

- Images : PNG, JPG, SVG
- Diagrammes : SVG, PlantUML, Mermaid
- Documents : PDF

## Taille des Fichiers

Pour les fichiers volumineux (>10MB), privilégiez :
- Les liens vers des services de stockage externe
- La compression des fichiers
- Les références plutôt que les copies
