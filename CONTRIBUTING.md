# Guide de Contribution

Merci de votre intérêt pour contribuer à ce dépôt !

## Comment Contribuer

### Ajout de Nouveaux Fichiers

1. **Choisissez le bon répertoire** :
   - `docs/` pour la documentation
   - `src/` pour le code source
   - `data/` pour les données
   - `examples/` pour les exemples
   - `resources/` pour les ressources multimédias

2. **Nommage des fichiers** :
   - Utilisez des noms descriptifs et clairs
   - Préférez les minuscules et les tirets (`-`) aux espaces
   - Exemple : `mon-document.md`, `script-analyse.py`

3. **Documentation** :
   - Ajoutez des commentaires dans votre code
   - Créez un README.md dans les sous-répertoires si nécessaire
   - Expliquez le contexte et l'objectif de vos fichiers

### Structure Recommandée pour les Commits

```
type: description brève

Description détaillée si nécessaire
```

Types de commits :
- `ajout:` pour de nouveaux fichiers
- `modif:` pour des modifications
- `doc:` pour la documentation
- `fix:` pour des corrections

### Exemple de Workflow

1. Ajoutez vos fichiers dans le répertoire approprié
2. Vérifiez que vos fichiers sont bien organisés
3. Committez avec un message descriptif
4. Poussez vos modifications

## Bonnes Pratiques

- **Clarté** : Vos fichiers doivent être compréhensibles
- **Organisation** : Respectez la structure des répertoires
- **Documentation** : Documentez vos fichiers complexes
- **Taille** : Évitez les fichiers trop volumineux (>10MB)

## Questions ?

N'hésitez pas à ouvrir une issue pour toute question ou suggestion d'amélioration.
