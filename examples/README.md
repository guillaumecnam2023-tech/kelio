# Exemples

Ce répertoire contient des exemples et des templates.

## Contenu

- Exemples de code
- Templates de documents
- Cas d'utilisation
- Tutoriels

## Utilisation

Les fichiers de ce répertoire servent de point de départ pour créer vos propres fichiers. Copiez et adaptez-les selon vos besoins.

## Types d'Exemples

- `templates/` : Modèles de documents
- `code-samples/` : Exemples de code
- `tutorials/` : Tutoriels pas à pas
