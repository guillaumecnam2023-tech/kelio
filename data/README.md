# Données

Ce répertoire contient les fichiers de données.

## Contenu

- Fichiers CSV
- Fichiers JSON
- Bases de données
- Jeux de données pour analyse

## Format

Privilégiez les formats standards et ouverts :
- CSV pour les données tabulaires
- JSON pour les données structurées
- XML si nécessaire

## Documentation

Pour chaque fichier de données, documentez :
- La source des données
- La date de collecte
- Le format et la structure
- Les unités de mesure si applicable
