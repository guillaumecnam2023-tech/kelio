# Documentation

Ce répertoire contient toute la documentation du projet.

## Contenu

- Guides utilisateur
- Documentation technique
- Notes de cours
- Rapports
- Présentations

## Organisation

Organisez les documents par catégorie ou par sujet. Utilisez des sous-répertoires si nécessaire.

## Formats Recommandés

- Markdown (`.md`) pour la documentation textuelle
- PDF pour les documents finalisés
- LaTeX pour les documents académiques
